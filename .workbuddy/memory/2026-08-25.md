### 追加：手动触发构建（2026-08-25 晚）
- 用户需求：少量改代码但不发版本时，可手动触发构建（构建+推送镜像，不创建 Release）。
- 决策（用户确认推荐项）：手动构建 = 构建产物 + 多架构推送 GHCR（标签 `dev-<分支>-<sha>` 与 `sha-<commit>`），**不建 GitHub Release**。
- 实现：
  - `.github/workflows/ci.yml` 增加 `workflow_dispatch` 触发器（手动跑 build+冒烟+k8s dry-run，不推送）。
  - 新增 `.github/workflows/manual-build.yml`（仅 `workflow_dispatch`），输入项 `image_tag`(默认空→自动生成)、`push_images`(默认 true)、`smoke_test`(默认 true)；job: build(算标签+产物+上传) → images(矩阵5镜像，gated by push_images) + smoke-test(gated by smoke_test，镜像本地 `:ci` 构建 + compose 冒烟 + k8s dry-run)。
  - 同步更新根 README CI/CD 表与 `deploy/README.md`（表 + 手动构建用法小节 + GHCR 标签说明）。
- 校验：5 个 workflow YAML 全部通过 PyYAML 语法校验。
- 注意：release.yml 故意不加 workflow_dispatch（会建 Release，与"不发版本"诉求冲突）；manual-build 才是未发版路径。

### 追加：手动构建首次运行失败排查（2026-08-25 晚）
- 现象：Manual Build #1 在 `Build artifacts (backend + frontend)` 步骤报错 `Can't find action.yml under .github/actions/build`。
- 根因：仓库 `.gitignore` 原有 `**/build` 规则，把本地创建的 composite action 目录 `.github/actions/build/` 整体忽略，导致该目录未被 commit/push，GitHub Actions runner 找不到 `action.yml`。
- 修复：在 `.gitignore` 末尾追加例外规则：
  ```
  !.github/actions/build/
  !.github/actions/build/**
  ```
  验证：`git status --short .github/actions/` 显示 `?? .github/actions/`（已解除忽略），`git add --dry-run` 可正常加入索引。
- 待用户操作：执行 `git add .github/actions/build/ .gitignore && git commit ... && git push` 后重新触发 Manual Build。

### 追加：docs.yml 生成 CHANGELOG 失败排查（2026-08-25 晚）
- 现象：Docs 工作流 #2 在 `Update CHANGELOG on main` 步骤失败，`git-cliff` 报错 `Filter "trim_start_matches" was called on an incorrect value: got 'null' but expected a String`。
- 根因：`cliff.toml` 模板里 `{{ version | trim_start_matches(pat="v") }}` 在 `docs.yml` 未传 `--tag` 时被调用，此时最新未发版区块的 `version` 为 `null`。
- 修复：在 `cliff.toml` 给 `version` 加 `default(value="Unreleased")` 兜底：`{{ version | default(value="Unreleased") | trim_start_matches(pat="v") }}`。
- 验证：`cliff.toml` TOML 语法校验通过。
- 说明：`2791 commit(s) were skipped due to parse error(s)` 只是历史提交不全是 Conventional Commits 的警告，不是失败原因。
- 待用户操作：提交推送 `cliff.toml` 修改后，`docs.yml` 会在下次 push 到 main 时自动重跑。
